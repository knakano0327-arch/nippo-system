## SC-001: ログイン画面

### 基本情報

| 項目 | 内容 |
|------|------|
| 画面ID | SC-001 |
| 画面名 | ログイン画面 |
| URL | `/login` |
| 対象ユーザー | 全ユーザー |
| 遷移元 | - （起点） |
| 遷移先 | SC-002 ダッシュボード |

### 画面項目

| 項目名 | 種別 | 必須 | 桁数・形式 | 備考 |
|--------|------|------|-----------|------|
| メールアドレス | テキスト入力 | ○ | 最大255文字 / メール形式 | |
| パスワード | パスワード入力 | ○ | 最大128文字 | マスク表示 |
| ログインボタン | ボタン | - | - | |

### アクション

| アクション | 処理内容 |
|-----------|---------|
| ログインボタン押下 | 入力値でサーバー認証を実施。成功時はSC-002へ遷移。失敗時は「メールアドレスまたはパスワードが正しくありません」とエラー表示。 |

### バリデーション

| 対象項目 | ルール | エラーメッセージ |
|---------|--------|----------------|
| メールアドレス | 必須・メール形式 | 「メールアドレスを正しい形式で入力してください」 |
| パスワード | 必須 | 「パスワードを入力してください」 |

## SC-002: ダッシュボード（日報一覧）

### 基本情報

| 項目 | 内容 |
|------|------|
| 画面ID | SC-002 |
| 画面名 | ダッシュボード（日報一覧） |
| URL | `/` |
| 対象ユーザー | 全ユーザー |
| 遷移元 | SC-001、SC-003、SC-004 |
| 遷移先 | SC-003（新規作成）、SC-004（詳細） |

### 表示内容

**営業（一般）の場合：** 自分の日報のみ表示  
**上長・管理者の場合：** 部下全員の日報を表示

### 検索フィルター

| 項目名 | 種別 | 備考 |
|--------|------|------|
| 期間（From） | 日付選択 | デフォルト：当月初日 |
| 期間（To） | 日付選択 | デフォルト：当日 |
| 担当者 | ドロップダウン | 上長・管理者のみ表示。「全員」選択可 |
| 検索ボタン | ボタン | |

### 一覧表示

| カラム名 | 内容 | 備考 |
|---------|------|------|
| 日付 | 日報の対象日 | 降順ソート（デフォルト） |
| 担当者名 | 作成した営業の氏名 | 上長・管理者のみ表示 |
| 訪問顧客数 | 当日の訪問件数 | |
| ステータス | 下書き / 提出済み / 確認済み | バッジ表示 |
| コメント有無 | 上長コメントの有無 | アイコン表示 |
| 操作 | 「閲覧」ボタン / 「編集」ボタン | 編集は本人・下書き時のみ表示 |

### アクション

| アクション | 処理内容 |
|-----------|---------|
| 「新規作成」ボタン押下 | SC-003（新規作成モード）へ遷移 |
| 「閲覧」ボタン押下 | SC-004へ遷移 |
| 「編集」ボタン押下 | SC-003（編集モード）へ遷移 |

## SC-003: 日報作成・編集画面

### 基本情報

| 項目 | 内容 |
|------|------|
| 画面ID | SC-003 |
| 画面名 | 日報作成・編集画面 |
| URL | `/reports/new` （新規）/ `/reports/:id/edit` （編集） |
| 対象ユーザー | 営業（本人のみ） |
| 遷移元 | SC-002 |
| 遷移先 | SC-002（保存後）、SC-004（提出後） |

### 画面項目

#### ヘッダー部

| 項目名 | 種別 | 必須 | 形式 | 備考 |
|--------|------|------|------|------|
| 日付 | 日付選択 | ○ | YYYY-MM-DD | デフォルト：当日。1人1日1件のみ作成可 |
| 作成者 | テキスト（表示のみ） | - | - | ログインユーザー名を自動セット |

#### 訪問記録部（複数行）

| 項目名 | 種別 | 必須 | 形式 | 備考 |
|--------|------|------|------|------|
| 顧客名 | ドロップダウン（検索可） | ○ | - | 顧客マスタから選択 |
| 訪問内容 | テキストエリア | ○ | 最大1000文字 | 商談内容・目的・結果など |
| 行削除ボタン | ボタン | - | - | 各行右端に配置。1行目は削除不可 |
| 行追加ボタン | ボタン | - | - | 「＋ 訪問先を追加」 |

#### Problem / Plan部

| 項目名 | 種別 | 必須 | 形式 | 備考 |
|--------|------|------|------|------|
| Problem（今の課題・相談） | テキストエリア | - | 最大2000文字 | 上長への相談も記入 |
| Plan（明日やること） | テキストエリア | - | 最大2000文字 | |

### アクション

| アクション | 処理内容 |
|-----------|---------|
| 「一時保存」ボタン押下 | ステータスを「下書き」で保存。SC-002へ遷移 |
| 「提出」ボタン押下 | バリデーション後、ステータスを「提出済み」で保存。SC-004へ遷移 |
| 「キャンセル」ボタン押下 | 確認ダイアログ表示後、SC-002へ遷移（未保存データは破棄） |

### バリデーション

| 対象項目 | ルール | エラーメッセージ |
|---------|--------|----------------|
| 日付 | 必須・日付形式 | 「日付を入力してください」 |
| 日付 | 同一日付の日報が存在しない | 「この日付の日報はすでに作成されています」 |
| 顧客名（各行） | 必須 | 「顧客を選択してください」 |
| 訪問内容（各行） | 必須・1000文字以内 | 「訪問内容を入力してください」「1000文字以内で入力してください」 |
| Problem | 2000文字以内 | 「2000文字以内で入力してください」 |
| Plan | 2000文字以内 | 「2000文字以内で入力してください」 |

## SC-004: 日報詳細・確認画面

### 基本情報

| 項目 | 内容 |
|------|------|
| 画面ID | SC-004 |
| 画面名 | 日報詳細・確認画面 |
| URL | `/reports/:id` |
| 対象ユーザー | 全ユーザー（上長は部下の日報も閲覧可） |
| 遷移元 | SC-002、SC-003 |
| 遷移先 | SC-002 |

### 表示内容

#### ヘッダー部（表示）

| 項目名 | 内容 |
|--------|------|
| 日付 | 対象日 |
| 作成者 | 担当営業氏名 |
| ステータス | 下書き / 提出済み / 確認済み（バッジ表示） |
| 作成日時 | 日報の作成・更新日時 |

#### 訪問記録部（表示）

| 項目名 | 内容 |
|--------|------|
| No. | 行番号 |
| 顧客名 | 訪問した顧客の名称 |
| 訪問内容 | 記入内容 |

#### Problem / Plan部

| エリア | 内容 |
|--------|------|
| Problem | 課題・相談内容の表示 |
| Plan | 翌日の行動計画の表示 |

#### コメント部（上長のみ入力可）

| 項目名 | 種別 | 必須 | 形式 | 備考 |
|--------|------|------|------|------|
| コメント対象 | 表示ラベル | - | - | 「Problem へのコメント」/ 「Plan へのコメント」 |
| コメント内容 | テキストエリア | ○（送信時） | 最大1000文字 | |
| 「コメントを送信」ボタン | ボタン | - | - | 上長・管理者のみ表示 |
| 既存コメント一覧 | 表示 | - | - | コメント者・日時・内容を表示 |

### アクション

| アクション | 権限 | 処理内容 |
|-----------|------|---------|
| 「編集」ボタン押下 | 本人（下書きのみ） | SC-003（編集モード）へ遷移 |
| 「確認済みにする」ボタン押下 | 上長・管理者 | ステータスを「確認済み」に更新 |
| 「コメントを送信」ボタン押下 | 上長・管理者 | Problemまたは Plan へのコメントを保存し、画面を再描画 |
| 「一覧へ戻る」ボタン押下 | 全ユーザー | SC-002へ遷移 |

### バリデーション

| 対象項目 | ルール | エラーメッセージ |
|---------|--------|----------------|
| コメント内容 | 必須・1000文字以内 | 「コメントを入力してください」「1000文字以内で入力してください」 |

## SC-008: 営業マスタ登録・編集画面

### 基本情報

| 項目 | 内容 |
|------|------|
| 画面ID | SC-008 |
| 画面名 | 営業マスタ登録・編集画面 |
| URL | `/master/salespersons/new` （新規）/ `/master/salespersons/:id/edit` （編集） |
| 対象ユーザー | 管理者 |
| 遷移先 | SC-007（保存後） |

### 画面項目

| 項目名 | 種別 | 必須 | 桁数・形式 | 備考 |
|--------|------|------|-----------|------|
| 氏名 | テキスト入力 | ○ | 最大50文字 | |
| メールアドレス | テキスト入力 | ○ | 最大255文字 / メール形式 | ログインIDとして使用 |
| 初期パスワード | パスワード入力 | ○（新規のみ） | 8文字以上 | 編集時は変更する場合のみ入力 |
| 所属部署 | テキスト入力 | - | 最大100文字 | |
| 上長フラグ | チェックボックス | - | - | ONの場合、部下の日報へのコメント・確認が可能 |

### バリデーション

| 対象項目 | ルール | エラーメッセージ |

| 氏名 | 必須・50文字以内 | 「氏名を入力してください」 |
| メールアドレス | 必須・形式・重複なし | 「メールアドレスを正しい形式で入力してください」「このメールアドレスはすでに登録されています」 |
| 初期パスワード | 必須（新規）・8文字以上 | 「パスワードは8文字以上で入力してください」 |
